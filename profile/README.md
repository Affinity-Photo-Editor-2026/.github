## Main Features and Image Editing Workflows

### 1. Photo Retouching

Affinity Photo provides pixel-based editing tools for refining portraits, product images, landscapes, and other photographs. Users can remove unwanted distractions, correct selected details, and improve the visual balance of an image.

Retouching workflows often combine selection tools, brushes, masks, and separate layers. Keeping edits organized makes it easier to compare results and revise individual changes without rebuilding the entire composition.

### 2. RAW Image Development

RAW development tools help transform supported camera files into editable images. Photographers can adjust exposure, white balance, contrast, color, and detail before moving into more detailed pixel editing.

The available controls depend on the source file and application capabilities. For best results, begin with basic tonal and color corrections, then proceed to localized refinements after the overall image is balanced.

### 3. Layer-Based Editing

Layers allow separate visual elements to be stacked and adjusted independently. A project might contain a base photograph, retouching layers, text, graphic elements, masks, and color adjustments.

Clear layer names and logical grouping make complex projects easier to navigate. This structure also helps preserve the original image while allowing individual components to be modified later.

### 4. Masks and Selective Adjustments

Masks control which parts of a layer or adjustment affect the visible image. They are useful for refining a subject separately from its background, blending multiple photographs, or limiting a color correction to a specific region.

Careful masking helps maintain natural edges and smooth transitions. Refining masks at different zoom levels can reduce unwanted halos and make composite images appear more coherent.

### 5. Color and Tonal Correction

Color correction tools help adjust brightness, contrast, white balance, saturation, and tonal relationships. These adjustments can be used to correct capture conditions or establish a consistent creative style.

A practical workflow starts with overall exposure and neutral color balance before moving to more specific color changes. Reviewing the image at both normal viewing size and close range helps reveal problems that might otherwise be missed.

### 6. Object Removal and Image Cleanup

Retouching tools can help remove distracting objects, marks, blemishes, and other unwanted details from photographs. The appropriate method depends on the complexity of the background and the amount of surrounding image information available.

Simple areas may require only a small correction, while textured or irregular backgrounds can need more careful manual refinement. Inspect the result at the original viewing size to ensure that the edited region blends naturally.

### 7. Compositing and Creative Manipulation

Compositing combines elements from multiple images into a single visual composition. Separate layers, selections, masks, and transformation controls help position and blend each element.

Matching lighting, color temperature, scale, perspective, and edge detail is important when combining source images. A consistent approach to these factors helps the final composition look intentional rather than assembled from unrelated parts.

### 8. Brushes, Painting, and Local Refinement

Painting tools support manual adjustments, masking, detail work, and creative image treatments. Brush settings such as size, hardness, opacity, and flow affect how strokes interact with the image.

Using separate layers for experimental painting and retouching makes changes easier to control. A light, gradual approach is often useful when blending corrections into areas with subtle texture or tonal variation.

### 9. Selection and Precision Editing

Selection tools isolate specific image regions so that transformations, filters, and adjustments can be limited to the intended area. This is useful for editing individual objects, separating foreground elements, and preparing assets for compositing.

Selections may require refinement around hair, transparent objects, intricate contours, or areas with similar colors. Combining selection tools with masks can provide additional control over the final edge.

### 10. Text, Shapes, and Graphic Elements

Affinity Photo can combine photographs with text, shapes, and other visual elements to create composite graphics. This is useful for promotional images, social graphics, presentation visuals, and photographic layouts.

Keeping text and graphic elements on separate layers makes it easier to adjust placement, hierarchy, color, and scale. Check readability and contrast against the underlying photograph before exporting the finished design.

### 11. Filters and Effects

Filters and effects can alter texture, sharpness, blur, lighting, and other image characteristics. They may be used for subtle finishing adjustments or more stylized visual treatments.

Apply effects with a clear purpose and review their impact on important image details. Where supported, non-destructive methods help preserve flexibility by allowing settings to be revisited instead of permanently altering the source pixels.

### 12. Export and File Preparation

Export settings determine how the finished image is saved for its intended destination. Depending on the required workflow, users can select an appropriate format, image dimensions, and other available output options.

Retain an editable project file when future revisions may be needed, and create separate exported copies for delivery. Before sharing or archiving an image, inspect the output to confirm that its appearance, dimensions, and file format meet the requirements.
